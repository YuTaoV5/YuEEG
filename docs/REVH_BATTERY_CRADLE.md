# Rev H NP-BX1 电池座机械样件

当前已设计三个实体零件：承托底座、电源条板压条、可调后挡块，并导出 [STEP／STL 与装配图](../hardware/YuEEG_8CH_RevH_Stack/mechanical/current/battery_cradle/README.md)。这是可供机械打样复核的设计，尚未完成生产装配放行。原始电池 STEP／JPG 不在发布目录中。

## 结构与坐标

沿用当前三板布局：模拟板 F 面 Z=0，数字板 B/F 面 Z=8.5/10.1 mm；电源条板 F/B 面 Y=−4.05/−3.05 mm，电池接触端朝 Y=0。电池与叠层板并排，PCB、探针、JP2 及其他电路位置均未改变。

底座承托面 Z=8.7 mm，导向内宽 30.3 mm。左侧导向分成前后两段，为四线供电线束让位；右侧导向和前端压边保留电池上方的拆装空间。前端两个防呆键伸入模型的下角缺口 0.8 mm；缺口深度依据为 2.0 mm。顶部压边内表面 Z=18.1 mm，不能靠探针承担电池保持力。

条板由两侧背托、下止挡和可拆压条定位。设计前后总游隙 0.2 mm，名义板厚 1.0 mm；这不是板厂厚度公差承诺。条板焊好后，应在夹具中确认探针法兰贴合与端头居中，再锁定。壳体仍须承托底座、限定其与叠层板的相对位置并隔开外部导体；本样件不是完整外壳或屏幕支架。

后挡块沿 Y 可调 ±0.5 mm，适配工程验收长度 42.2…43.2 mm。用户模型的实际实体长度为 42.7500002 mm，对应本次后挡块位移约 +0.050 mm。装配 STEP 采用这一位置；单件 STEP／STL 是零位几何。后挡块的孔为长圆孔，螺钉轴固定在底座上，不随挡块移动。

## 紧固与拆装

使用四颗 M2×8 尼龙螺钉和四颗尼龙螺母。尺寸参考选定 Essentra **50M020040P008** 与 **04M020040HN**，具体数据、来源散列及包络见 `battery_cradle_hardware.json`。未核实淘宝对应 SKU，不得将任意 M2 五金直接当作等效件。

螺钉头预算 Ø4.2×1.6 mm，杆部预算 Ø2.1 mm；螺母预算外接圆 Ø4.9、厚 1.6 mm。螺母厂家图的对边尺寸为 3.90±0.26 mm、厚度 1.20±0.26 mm；按规则六边形推导最大外接圆约 4.804 mm，故预算向上取整。显式公差只计一次。[厂家螺母图纸](https://mm.digikey.com/Volume0/opasdata/d220001/medias/docus/936/04M020040HN.PDF)

压条两颗螺钉从外侧 −Y 向电池侧 +Y 装入，轴为 (47.5,−5,19)、(87.8,−5,19) mm；螺母位于背托的 +Y 面。后挡块两颗螺钉从上方装入，轴为 (58,47,10.7)、(82,47,10.7) mm，螺母在底座下方。已检查螺钉最长长度、头部／螺母空间及直径 Ø4.2、长 15 mm 的螺丝刀杆接近空间。该空间不代表任何实际批头／扳手已经选型，侧向夹持螺母的工具和扭矩仍待装配验证。

装入电池时，先取下后挡块，从后方沿 −Y 平移，使前端缺口进入防呆键、接触面贴近前止挡；随后调整后挡块并固定。拆卸时先断电，取下后挡块，将电池向 +Y 平移至少 4.5 mm 后再抬起。不要直接撬起接触端或用螺钉强压电池。

## 打样及接收条件

材料与加工方法尚未定型。STEP 使用 mm；STL 无单位，导入时必须指定 mm。先制作尺寸样件，确认加工收缩、孔形、压条及长圆孔、键的实际位置和装配路径；不得仅凭这些文件直接发布整机生产订单。

交付 Sony 电池必须核对极性、触点平面、缺口与模型的一致性。当前宽度 29.29…29.95 mm、厚度 9.0…9.3 mm、长度 42.2…43.2 mm 是项目接收目标，不是 Sony 公差。若不满足，应改座体与探针对齐，不能削改电池或强行插入。

实测探针工作高度目标 3.6…4.0 mm；按自由高度 4.35…4.65 mm 计算，压缩范围为 0.35…1.05 mm。端头中心相对 PCB 的装配误差目标 ≤0.2 mm，端头圆盘到有效金属接触面边缘至少留 0.3 mm；这些指标均待实物验收。探针必须先做绝缘限位与极性检查，再连接电源。

保持力试验目标 5 N 是本项目选择的台架验收值，尚未测试，不是材料强度结论。锁紧扭矩、尼龙吸湿／蠕变、反复装卸磨损、振动、温升和探针接触稳定性均需验证。屏幕背面 Z 基准、支撑件、整机固定及绝缘复核继续作为独立未完成项，不能由这套电池座模型代替。

## 复算

在项目根目录运行；原始模型只在本机作为输入。CadQuery 可安装在独立环境，或使用本地 `logs/mechanical_runtime`，不会随工程发布。

```powershell
python hardware/YuEEG_8CH_RevH_Stack/review/devtools/build_h_battery_cradle.py --battery-step '<本机的 NPBX1.STEP>' --output logs/battery_cradle_candidate
& 'X:/SoftWare/Kicad/bin/python.exe' hardware/YuEEG_8CH_RevH_Stack/review/devtools/extract_h_cradle_power_envelopes.py --output logs/battery_cradle_candidate/power_component_envelopes.json
python hardware/YuEEG_8CH_RevH_Stack/review/devtools/check_h_battery_cradle_clearance.py --artifacts logs/battery_cradle_candidate
```

复算输出属于候选结果。核对实体、图示、全部输入和文件散列后，才能更新发布的机械检查点；复算不会自动覆盖正式 PCB、既有工程制造文件或发布状态。
