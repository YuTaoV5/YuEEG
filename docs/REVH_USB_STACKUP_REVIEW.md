# Rev H USB 布线与叠层复核

本轮增加了两处器件侧 GND 回流过孔（孔径 0.20 mm、焊盘 0.45 mm）：MCU 端 (2.55,19.45)，隔离器端 (14.35,37.65)。相邻 USB 信号过孔到这些地孔的中心距离分别为 0.65／0.68 mm、1.09／1.30 mm。均位于器件侧，没有跨接主机地与采集地。记录见数字板 `review/usb_return_vias.json`；原生 DRC、未连接及原理图一致性检查通过。

`review/usb_geometry.json` 从当前原生 PCB 提取分层线宽、平面中心线长度与信号过孔坐标。长度不含孔桶、焊盘与封装。补地孔只缩短换层附近的参考地路径，不能据此宣称阻抗或 USB 眼图合格。

本次测量中，USB_DOWN_DM／DP 的**全网铜线长度之和**均约 33.722 mm，其中 In2.Cu 各约 31.782 mm，线宽均为 0.15 mm；USB_MCU_DM／DP 各 2.140 mm。USB_UP_DM／DP 为 2.209／4.540 mm，USB_HOST_DM／DP 为 20.828／23.271 mm，且 HOST_DP 有内层段。主机网络包含 Type-C 重复触点连接及 ESD 分支，不能把全网长度之和相减，直接当作端到端时延失配。需继续检查实际传播路径、分支与环路，不能据此宣称整条 USB 链路已通过复核。

后续在主机侧增加两处 HOST_GND 回流孔：(23.70,49.40)、(27.85,49.40) mm。对应信号过孔到最近参考地孔的中心距离从 6.70／10.74 mm 缩短为 1.38／1.08 mm。参考地仍与采集 GND 分离；原生 8 mm 域间规则继续启用，DRC／未连接／原理图一致性检查通过。记录见 `review/usb_host_return_vias.json`。

`review/usb_reference_coverage.json` 对 53 段 USB 铜线按不大于 0.1 mm 的间距采样中心线：F.Cu 检查 In1.Cu，In2.Cu 同时检查相邻 In1／In3；分别选择 GND 或 HOST_GND。发现的 78 个无参考铜采样点均落在信号过孔焊盘半径加 0.17 mm 的邻域内，未发现该邻域外的中心线缺铜采样点。这是有限分辨率、仅中心线的静态筛查，不能证明整条参考地回流连续、迹线全宽有覆盖或实际阻抗合格。

数字板为六层，原生文件尚未写入最终压合叠层。可供板厂核对的候选是 [嘉立创官方 JLC06161H-3313 叠层](https://jlcpcb.com/impedance)：外铜 0.035 mm、内铜 0.0152 mm；由上至下的介质为 3313 0.09940、core 0.55、2116 0.1088、core 0.55、3313 0.09940 mm。官方介电常数分别为 4.1、4.6、4.16。该表列出的铜与介质厚度合计 1.5384 mm，而类别标称为 1.6 mm，需板厂解释成品厚度口径，不能自行修改介质厚度凑数。

候选参数尚未应用到 PCB，也没有完成场求解或厂家阻抗计算。当前差分线宽不能视为已满足 90Ω。最终需要依据实际层间距离、压合后厚度、铜厚和同层间距求解，并检查差分对全路径与地平面的连续性，再按结果调整布线和制造要求。[TI 的 USB 布局资料](https://www.ti.com/video/6087491555001)也将阻抗、线长匹配与板层结构作为联合检查项。

本轮还加入功能区名称和避让器件的圆角虚线分区；完整分区轮廓保留于 Dwgs.User。它们用于识别功能，不是绝缘边界或屏蔽结构。电池触点、显示屏 FPC、成品叠层与台架采集验证仍未完成；工程导出不可直接下单。
