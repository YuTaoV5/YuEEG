# YIMU v1 运动数据协议

固定128字节、小端整数／IEEE754 float32，魔术字 `YIMU`。它与原有50字节 `YEEG` v1分开编码，USB可混流；Wi-Fi运动数据独立发往同一目标IP的UDP9002；SD文件为 `imu_XXXXXX.yim`。接收工具验证整个帧后一次消费，不能在有效载荷内重新搜索魔术字。

| 偏移 | 长度 | 类型／内容 |
| --- | --- | --- |
| 0 | 4 | ASCII `YIMU` |
| 4 | 1 | 版本=1 |
| 5 | 1 | 帧长=128 |
| 6 | 2 | uint16质量位，见下表 |
| 8 | 4 | uint32输出记录序号，模2³² |
| 12 | 8 | uint64单调微秒时间；正常样本为DRDY中断时间，故障／停止状态帧为生成时的主机时间 |
| 20 | 4 | uint32最近已处理EEG样本序号 |
| 24 | 4 | uint32该EEG样本的原有微秒时间，模2³²；0表示尚无关联样本 |
| 28 | 4 | uint32遗漏样本下界累计数；IRQ和数据计数描述同一次遗漏时不重复累加 |
| 32 | 4 | uint32拒收／连续性异常累计次数 |
| 36 | 12 | float32[3]传感器轴角速度，°/s |
| 48 | 12 | float32[3]传感器轴加速度，m/s²，含重力对应的比力项 |
| 60 | 16 | float32[4]四元数w,x,y,z；传感器轴→局部Z向上坐标 |
| 76 | 12 | float32[3]局部速度，m/s |
| 88 | 12 | float32[3]局部位移，m |
| 100 | 4 | float32传感器温度，°C |
| 104 | 4 | float32距离最近成功对准的秒数；未对准时为0 |
| 108 | 1 | 陀螺组4位数据计数，0…15；无有效样本时255 |
| 109 | 1 | 加速度组4位数据计数，0…15；无有效样本时255 |
| 110 | 2 | 保留，0 |
| 112 | 4 | uint32坐标原点ID；每次成功静止对准递增，开机时使用随机种子 |
| 116 | 4 | uint32 DRDY到本次读取完成的微秒数；无实际读取的状态帧为0 |
| 120 | 4 | uint32运动输出队列丢弃记录数；USB／UDP／SD各自计数另由status提供 |
| 124 | 2 | 保留，0 |
| 126 | 2 | CRC16-CCITT，初值FFFF，多项式1021，覆盖字节0…125，结果小端 |

累积计数指本次MCU开机运行；`imu start`不会把历史错误清零。4位传感器计数回卷不能恢复整周遗漏，因此不能把遗漏下界当作完整丢样总数。记录序号是约50Hz输出序号，不是每个传感器样本的序号；固件逐合格样本积分后降频输出。

| 位掩码 | 名称 | 含义 |
| --- | --- | --- |
| 0001 | sensor_valid | 本次原始样本通过帧／类型／同组三轴代际和时序检查，不代表此前没有丢样 |
| 0002 | attitude_valid | 已静止对准并有连续的姿态解算状态，不是误差保证 |
| 0004 | trajectory_valid | 当前3秒相对积分窗口有效 |
| 0008 | warmup | 本次IMU启动后不足15分钟的提示，不证明热稳定与否 |
| 0010 | yaw_unreferenced | 航向没有外部参考；本版始终置位 |
| 0020 | position_relative | 位移仅相对本次对准原点；本版始终置位 |
| 0040 | sample_gap | 解算遇到连续性故障，须重新对准 |
| 0080 | aligning | 正在用户明确请求的静止对准中 |
| 0100 | window_expired | 3秒积分窗口已到期 |
| 0200 | sensor_fault | 当前采样／时序异常；无数据心跳也会置位 |
| 0400 | eeg_active | 当时EEG采集模式处于运行状态；不证明同一瞬间采样 |
| 0800 | align_rejected | 对准未通过检查 |
| 1000 | stopped | 软件IMU采样停止 |
| 2000 | hardware_unverified | 本版始终置位，尚未完成实物验证 |
| 4000 | tilt_feedback | 当前姿态使用了加速度倾角反馈；不在有效轨迹窗口内 |

掩码按十六进制表示。姿态无效时四元数字段为NaN；轨迹无效时速度／位移为NaN。不得把过期值、NaN或最后一条历史记录显示为当前有效位置。实时设备状态在超过250ms没有新发布时撤销有效位；接收工具超过0.5秒无运动记录会提示数据陈旧。样本有效、预热、未经硬件验证等标记可以同时存在。

重对准会建立新的局部方向、初速和原点，接收端按 `origin_id` 分段，不能跨原点拼接连续位置。该ID不是全球唯一设备标识。`eeg_seq`／`eeg_us32` 只用于关联最近处理样本；它们不包含IMU／EEG滤波群延迟或时钟标定。

姿态核心、物理单位和使用步骤见[相对运动说明](REVH_INDOOR_NAV.md)。软件通过测试与编译不等于完成实物惯导精度、并发采集或人体连接验证。
