# Rev H 电池探针孔径与加工公差

2026-11-01。电源条板 JP1 两个成品金属化孔由 **0.60 改为 0.70 mm**；焊盘仍为1.30 mm，针号、10 mm中心距、位置、走线、过孔、其余元件和电池名义姿态均保持。此修改增加普通插件孔加工公差下的焊接间隙，不能代替探针居中夹具或电池仓止挡。

## 尺寸依据与计算

[Mill-Max 精确料号四页规格书](https://static.chipdip.ru/lib/770/DOC031770063.pdf)的尺寸图给出尾针直径0.017英寸，标准直径公差±0.002英寸；第2页建议最小成品孔比待焊直径大0.004英寸。本项目按尾针最大值保守计算：

- 最大尾针：(0.017+0.002)×25.4 = **0.4826 mm**。
- 建议最小成品孔：0.4826+0.004×25.4 = **0.5842 mm**。

[嘉立创公开工艺参数](https://www.jlc.com/portal/vtechnology.html)列出插件孔+0.13/-0.08 mm。以该公开能力作为参考，旧0.60 mm孔的允许下限为0.52 mm，虽然仍大于上述尾针最大值，直径间隙却只有0.0374 mm，低于所用焊接间隙建议。新0.70 mm孔的参考范围为 **0.62…0.83 mm**，最小直径间隙0.1374 mm，比建议多0.0358 mm。

1.30 mm焊盘与0.83 mm孔的同心几何焊环为0.235 mm；这不包含孔位偏移和铜蚀刻误差。实际板厂及工艺必须确认；孔径是成品孔要求，不能自行在导出文件中另加电镀补偿。

新孔不是压配孔。装配时须将两个探针用夹具维持10 mm中心距、法兰贴平B面后焊接，不得依靠较松的孔径自行居中。电池插拔和外壳载荷由独立固定结构承受。

## 同料号资料的冲突

精确料号PDF的尺寸图将0906-1的A列为0.177英寸（4.4958 mm），与[原厂家目录](https://www.mill-max.com/sites/default/files/external/catalog/2019-04/023M-028M.pdf)的4.5 mm一致；同一PDF的通用信息栏却写3.48 mm，后者对应0906-0档。本项目继续按明确的0906-1图纸档位设计，来料须核对，不以矛盾的通用栏缩短探针。

新版单件资料与旧目录的电流评级不同，设计继续保留保守的2 A连续／3 A峰值，没有提升板卡额定电流。预压力在分销表和旧厂家目录间也存在不同数字，不能据此定电池卡扣载荷。60 gf中行程力可作为名义参考，不能外推整个力曲线或保持力。

已找到精确料号的[DigiKey ED8181-ND条目](https://www.digikey.com/en/products/detail/mill-max-manufacturing-corp/0906-1-15-20-75-14-11-0/1147049)，页面显示可订购；这不是淘宝货源、交付尺寸或装配资格已经确认。原PDF只本地检查，来源散列与冲突处理记录在 `mechanical/current/pogo_source_and_hole_review.json`。

## BTB 定位孔的独立工艺要求

同一公开工艺表给出的常规NPTH公差为±0.10 mm。当前SGDCONN图要求JH1定位孔 **0.65 +0.03/-0 mm**；常规0.65 mm孔可能成为0.55…0.75 mm，不能满足该推荐范围。模拟／数字板每板两个此类孔必须由板厂单独接受其成品公差，不能按默认NPTH工艺直接下单，也不能未经复核扩大孔径。本次未修改这些定位孔。

当前仍为工程版。真实焊接间隙、法兰贴合、探针压缩、保持结构、电池接触面及屏幕装配尚需验收；孔径修正不解除制造放行条件。
