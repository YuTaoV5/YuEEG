# Rev H 屏幕短 FPC 加工几何复核

当前是工程样件，尚未获得工厂对层压、极限过孔及装配工艺的接受。主三板没有改动；本次修改的是[短 FPC 延长板](../hardware/YuEEG_8CH_RevH_Stack/display_link/YuEEG_H_DISPLAY_LINK.kicad_pcb)。

## 发现与改动

原文件按0.25mm铜到板边检查通过，但[板厂公开柔性板能力](https://jlcpcb.com/capabilities/flex-pcb-capabilities)给出0.30mm设计要求。按0.30mm复查，JF2两个固定焊盘到上端斜边约0.2575mm，不能由此前绿色DRC证明满足该工艺。

现将JF2端斜边起点向颈部方向延伸0.10mm，即距接头中心从1.55改为1.65mm；颈部侧终点仍为2.05mm。JF1端保持1.55／2.05mm，避免减少U1003附近空间。整体外形仍为8×13.531mm、颈宽5.1mm，两个连接器的坐标、全部56个焊盘尺寸与网络均未改变。

一段接地干线及相连馈线共4个线段的相关端点由X约1.90微调到1.91mm，保持连接和线宽；过孔不变。端部铺地间距由0.10增至0.15mm并重新填充，专用规则将外露SMD焊盘对其他网络铜的间距设为至少0.15mm，覆盖走线、过孔和地铺铜；同网的正常焊盘连接保留。

## 原生文件中的加工定义

`F.Adhes`现为两个**零线宽、实心填充**的F侧PI补强区域，目标厚0.20mm；不再用细线框让加工人员猜测实际边界。两接头仍装B面，B面盖膜采用接头整窗开口；全部焊盘到窗口边的名义余量至少0.10mm。`Cmts.User`在板外明确标注PI材料、25µm芯膜／每侧12µm基铜、0.11mm名义成品厚目标、补强面及工艺待确认项。

上述是工程目标。最终盖膜、胶层、镀铜与层压厚度分配没有得到工厂确认，因此原生文件没有填入虚构的逐层数值；不能把软件默认板材显示当作制造材料表。0.20mm补强、覆盖边界公差和一次静态折弯工艺也需工厂接受。0.10／0.30mm过孔属于所查二层FPC极限规格，需要明确确认，不能按普通FR-4板制作。
