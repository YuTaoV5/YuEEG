# YuEEG Rev D

KiCad 9 项目：`YuEEG_8CH_RevD.kicad_pro`。本版增加隔离 Type-C 数据与电源、USB/Wi-Fi 同时输出所需硬件、ESP32-S3-WROOM-1-N16R8、前端可旁路扩展以及状态显示接口。

- 板框 84 × 122 mm、四层、332 个元件、13 页原理图。板子扩大是为容纳隔离电源、全层隔离禁布区和模拟扩展连接器；Rev C 保留。
- Type-C 原生 USB CDC 串口/烧录经过 ADuM4160BRIZ；充电电源经过 THM 6-0511。HOST_GND 与系统 GND 分离，不将 USB 外壳接系统地。
- POWER ON：支持 USB CDC 和 Wi-Fi 同时输出，禁止电池充电。POWER OFF：符合供电条件时约 300 mA/8.2 V 充电。
- Type-C 广告 1.5 A/3 A 时允许隔离电源启动，可无电池烧录；普通 USB-A/default-current 端口只支持电池供电的数据通信，不能承诺充电或无电池启动。
- REF、BIAS 与通道 8→1 形成同一列接口；电解电容和 RESET/BOOT 按键仍在正面。
- 默认不装外部放大器，16 颗 0 Ω 旁路接通。J801/J802 提供八路 P/N 的发送/返回及模拟电源；连接有源子板前必须拆除相应 P/N 两颗旁路。
- LED：POWER、RUN、WIFI、FAULT，另有充电指示。J803 预留 3.3 V I²C OLED 接口，当前未包含屏幕或显示驱动。
- 固件位于 `Firmware/ads1299_driver/`；项目打包内 `firmware/` 包含源码、说明、接收程序及编译产物。原文本绘图程序不兼容新的二进制帧。

设计取舍、隔离边界、USB 功率限制、扩展接口和保护见 `REV_D_REVIEW.md`。原生文件是交付基准，开发迁移脚本不能重复执行。

静态检查结果：ERC、DRC、未连接和原理图/PCB 一致性问题均为零，941 个引脚连接核对通过。固件已按 N16R8 配置编译，5 项协议测试通过；没有执行实物烧录。72 处焊盘内过孔要求填孔加铜封帽，投板前须阅读 `fabrication_review/ASSEMBLY_NOTES.md`。

这是工程评审稿。隔离器件的组件认证不等于整机人体使用放行；尚未执行真实烧录、USB 枚举、双路持续传输、湿电极噪声、温升、故障和隔离耐压/漏电流试验。UART 调试器、示波器、屏幕或扩展子板外部电源都可能绕过隔离，必须保持系统侧浮地。
